# The query Lambda's vendored closure (this branch only): LangGraph and everything it drags
# in, installed into services/query/vendor/ by scripts/build_lambda_deps.py as Linux cp312
# wheels. Do not `pip install -r` this into a development venv -- the Linux extension modules
# cannot load on Windows. tests/requirements-dev.txt is the counterpart for the unit tests.
#
# Every line is `==` on purpose. pydantic 2.13 and langchain-core 1.x move fast, and what was
# audited on 2026-09-10 (38 distributions, 11 native .so, 47.7 MiB unzipped) is this exact
# closure, not a version range; listing the transitive dependencies too leaves a resolver on
# another day nothing to choose.
#
# To regenerate after a deliberate upgrade, resolve the two roots into a scratch directory
# with the same platform flags the build script uses, then freeze what landed there:
#
#   python -m pip install --target <scratch> --platform manylinux2014_x86_64 --only-binary=:all: \
#       --python-version 3.12 --implementation cp --abi cp312 langgraph langchain-core
#   python -m pip freeze --path <scratch> | sort -f > services/query/requirements-lambda.txt
#
# Re-add this header, then run scripts/build_lambda_deps.py: it fails on a non-Linux wheel, a
# wrong ABI tag, an unpinned distribution, or an oversize tree before anything reaches cdk.
